## 1. 上传合约、功能检查和版本查询

## 2.增加，更新，删除链上目录

### (1).上传链上目录。

- **URL:** `/contract/datacatalog/publish`
- **方法:** `POST`
- **请求体参数:**

| **字段**       | **类型**   | **描述**                      |
| -------------- | ---------- | ---------------------------- |
| `id`           | `string`   | 目录的唯一标识符              |
| `name`         | `string`   | 目录名称                      |
| `code`         | `string`   | 在目录中的排序编号             |
| `orgId`        | `string`   | 组织名称或ID                  |
| `orgDID`       | `string`   | 组织去中心化标识符（DID）      |
| `remark`       | `string`   | 备注描述内容                  |

智能合约将自动更新如下字段：

| **字段**       | **类型**   | **描述**                      |
| -------------- | ---------- | ---------------------------- |
| `Version`      | `int`      | 标识相同id的目录在链上的储存版本，起始为1|
| `PublishTime`  | `number`   | 发布时间戳，应为unix时间戳（毫秒）      |
| `Status`       | `int`      | 标识链上状态，1为已上链，2为锁定，-1为不可用，-2为有新版本|

如下字段提供资产的具体描述，用于进行跨平台资产的流通，是可选内容

| **字段**       | **类型**   | **描述**                      |
| -------------- | ---------- | ---------------------------- |
| `PlatformName` | `string`   | 资产所属平台的名称             |
| `PlatformDID`  | `string`   | 资产所属平台的去中心化身份DID   |
| `PlatformURL`  | `string`   | 资产所属平台的具体url           |
| `DataVersion`  | `string`   | 描述资产或数据在平台上的版本     |
| `CreateTime`   | `string`   | 描述资产或数据在平台上的创建时间  |
| `AsseType `    | `string`   | 描述数字资产的具体类型           |
| `itemVOList`   | `ArrayList` | 子项列表，提供数据集的子项介绍，具体见[子项说明](#子项说明) |

具体字段可以在文件src/main/java/com/chainmaker/backendservice/dto/DataCatalogItemVO.java中检查

- **请求示例:**

Bash

```
curl -X POST http://localhost:8008/contract/datacatalog/publish \
  -H "Content-Type: application/json" \
  -d '  {
    "id": "TE_10000001",
    "name": "多语言对话文本对",
    "orgId": "语核智能-YH2024",
    "orgDID": "did:org:yuhe_intelligence_001",
    "code": "TE_10000001",
    "remark": "华东区业务语料归档"
  }'
```
- **成功响应:**

JSON

```
{"result":"c56fd9533b101026fd44f848672fbbe7e6cf8cad6f22270161dfa28b08aef433","bizCode":"SUCCESS","message":"publish success"}
```

- **失败响应:**

JSON

示例错误：400 (Bad Request)，缺少必需字段

```
{"field":"id","bizCode":"VALIDATION_ERROR","message":"field id must not be blank"}
```

示例错误：501 (Not Implemented)，请求体错误

```
{"status":"failed","code":501,"message":"Required request body is missing: public org.springframework.http.ResponseEntity<com.alibaba.fastjson.JSONObject> com.chainmaker.backendservice.api.CatalogController.newDataCatalog(java.lang.String)","data":null}
```

### (2).删除链上目录。

- **URL:** `/contract/datacatalog/delete`
- **方法:** `DELETE`
- **请求体参数:**

使用如下字段来定位需要删除的目录：

| **字段**       | **类型**   | **描述**                                                                 |
| -------------- | ---------- | ---------------------------- |
| `id`           | `string`   | 目录的唯一标识符      |
| `name`         | `string`   | 目录名称             |
| `code`         | `string`   | 代码或编号              |

- **请求示例:**

Bash

```
curl -X DELETE "http://localhost:8008/contract/datacatalog/delete" \
  -H "Content-Type: application/json" \
  -d '{
        "id": "TE_10000001",
        "code": "TE_10000001",
        "name": "多语言对话文本对"
      }'
```

- **成功响应:**

JSON

```
{"status":"success","code":200,"message":null,"data":{"result":"289803f1c245217453fa6de7a1ad3f6bca1a57273bb95a1e8b7fc92423261d19"}}
```
在删除后，会将链上状态从status=1转化为status=-1

即逻辑删除

删除后的字段在DataCatalog数据结构中不再可用，并且存在DataCatalogHistory数据结构中

### (3).更新链上目录。

- **URL:** `/contract/datacatalog/update`
- **方法:** `POST`
- **请求体参数:**

请求体参数见[上传目录](#1上传链上目录)

使用如下字段来定位需要更新的目录：

| **字段**       | **类型**   | **描述**                      |
| -------------- | ---------- | ---------------------------- |
| `id`           | `string`   | 目录的唯一标识符              |
| `name`         | `string`   | 目录名称                      |
| `code`         | `string`   | 在目录中的排序编号             |
| `expectedVersion`| `int`      | 需要与当前版本相同再次确认更改|

输入的其他字段将覆盖链上原有字段内容进行更新，智能合约会自动更新Version和PublishTime字段

旧的版本的目录状态将被更新为-2，表示有新版本，存入DataCatalogHistory数据结构中

- **请求示例:**

Bash
```
curl -X POST http://localhost:8008/contract/datacatalog/update \
  -H "Content-Type: application/json" \
  -d '{
    "id": "TE_10000002",
    "code": "TE_10000002",
    "name": "中文语言对话文本对",
    "expectedVersion": 2,
    "asseType": "文本数据集",
    "remark": "这是一个单中文文本的AI训练资料，华东区业务语料归档",
    "platform_name": "智能数据平台"
  }'
```

- **成功响应:**
JSON

```
{"status":"success","code":200,"message":null,"data":{"result":"47cddeb42682a4e91f8e24c92a8a34fb7b4cb3ed0f910e19848115cddc885eb4"}}
```
- **失败响应:**
JSON

```
{"status":"success","code":200,"message":null,"data":{"result":"Fail"}}
```

### (4).锁定/解锁链上目录。

- **URL:** `/contract/datacatalog/lock` `/contract/datacatalog/unlock`
- **方法:** `POST`
- **请求体参数:**


使用如下字段来定位需要锁定的目录：

| **字段**       | **类型**   | **描述**                      |
| -------------- | ---------- | ---------------------------- |
| `id`           | `string`   | 目录的唯一标识符              |
| `name`         | `string`   | 目录名称                      |
| `code`         | `string`   | 在目录中的排序编号             |

在交易中的资产将被锁定，无法进行修改和删除，锁定后状态为status=2
解锁后状态恢复为status=1

- **请求示例:**

Bash
```
curl -X POST http://localhost:8008/contract/datacatalog/lock \
  -H "Content-Type: application/json" \
  -d '{
    "id": "TE_10000002",
    "code": "TE_10000002",
    "name": "中文语言对话文本对"
  }'
```

- **成功响应:**
JSON

```
{"status":"success","code":200,"message":null,"data":{"result":"f3b8f4f3387cf75e071bc770dda16e42a918bb500712cd764ab267e8667a7f92"}}
```
- **失败响应:**
JSON

```
{"status":"success","code":200,"message":null,"data":{"result":"Fail"}}
```

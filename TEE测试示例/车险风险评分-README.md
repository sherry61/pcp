# 车险风险评分 TEE 上链登记场景

## 业务场景

卖方是一家保险公司，拥有经过多年理赔数据验证的车险风险评分模型。模型根据车主年龄、驾龄、违章次数、历史事故次数和车辆安全系数计算风险分。

卖方在上链登记资产时选择“可信执行环境（TEE）”，并上传本目录中的两个文件。文件会持久化保存在平台服务器，买方后续请求交付时由服务器自动送入 TEE 计算。

买方可以是互联网出行平台或车主服务平台。买方购买后只能下载 TEE 输出的风险评分结果，不能直接获取卖方的计算程序和内部运行环境。

## 文件对应关系

- `车险风险评分-data.csv`：待计算的车主/保单特征数据
- `车险风险评分-weight.csv`：卖方风险评分权重

两份文件的指标名称必须完全一致。`data.csv` 第一列为记录 ID，后续列为数值指标；`weight.csv` 第一列为指标名，第二列为数值权重。

## 预期计算结果

计算公式：

```text
score = age×0.10 + driving_years×0.15 + violations×0.25 + accident_count×0.30 + car_safety×0.20
```

## 上链登记操作

1. 资产名称填写“车险风险评分 TEE 计算服务”。
2. 资产交付方法选择“可信执行环境”。
3. 在出现的两个上传框中分别选择 data 和 weight 文件。
4. 完成登记后，确认 TEE 文件状态为已准备。

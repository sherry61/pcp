# TEE 固定加权交付测试文件

本目录用于当前 TEE 固定加权场景的端到端联调。

- 卖方在“执行交付”中选择 `卖方数据文件-data.csv`。
- 买方在“上传权重”中选择 `买方权重文件-weight.csv`。

数据文件第一列必须是记录标识；其余列为待计算指标。权重文件第一列是指标名、第二列是权重。指标名称需与数据文件表头严格一致。

本组样例的权重总和为 1，预期明文结果为：

| id | score |
| --- | ---: |
| sample-001 | 74 |
| sample-002 | 74 |
| sample-003 | 73 |

TEE 最终返回的是使用买方 weight 阶段 SM4 密钥加密的 JSON 结果；当前界面完成获取结果后应在浏览器侧解密查看。
